**Decisions made:**
- **Manual H&R buttons are always-fire** (owner-approved, PRD FR-AT-41 verbatim, over a strict transition-only toggle): every press logs the section event, fires the chimed announcement "regardless of segment boundaries", and idempotently sets/clears the override — one-tap recovery when GPS auto-fired a section start but missed the end. `ManualHailRideState` is therefore a dumb holder (the use case logs every press — deliberate contrast with `EmergencyMuteState`'s persist-before-reflect).
- **Focus-denial asymmetry:** a non-regulated announcement drops on an AudioFocus denial (breadcrumbed); regulated audio plays regardless (ledger #12's complement, owner-approved).
- **The speaker warning is driver-dismissible** (owner-chosen, PRD FR-AT-30 verbatim, over the plain GPS-marker mirror) — a fourth `DISMISSED` machine state, per-episode; dismiss affordance in the panel header only, strip marker non-interactive.
- **Muted state shows a third amber marker** (owner-approved): an engaged Emergency Mute is never visually normal with the panel closed.
- FR-AT-63 "audio device connected/disconnected" rows use the GPS-monitor persist-before-reflect shape; speaker submissions are journey-gated like GPS submissions, with the initial device evaluation deferred to first journey observation (keeps routeId real; closes the registration-time race).
- Emergency Mute toggles via a use case (it logs journey events), while the non-logging speaker-warning dismiss pokes the monitor directly — the codebase's dividing line for VM wiring.
- Volume keys are intercepted app-wide with `onKeyUp` also consumed (an unconsumed UP pops the system volume UI); `KEYCODE_VOLUME_MUTE` is consumed as a no-op; `AlertDialog` windows bypass the interception (accepted, transient — documented in `MainActivity`).
- `HailRideSectionController` is eager-constructed from `JourneyViewModel` as well as `LocationService` (plan-agent catch): on a GPS-permission-denied manual-mode tablet the service never starts, and the replay-0 announcement bus would have had no collector in exactly the scenario the fallback buttons exist for.
