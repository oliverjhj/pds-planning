# Session: 2026-07-23 — Public landing page (Phase 4 opened)

**What changed:** Phase 4's first item shipped and went live: `/` on `pds-dashboard.com` is now a public marketing landing page. The owner chose "Model A" after discussion — a standalone shop-window page, the dashboard untouched and gated exactly as before, with a session-aware header ("Sign up" for visitors, "Open dashboard" for a logged-in operator; no forced redirect) — and chose a **live tablet demo** as the hero centrepiece over generic 3D/WebGL flair. Built as a new `(marketing)` route group (layout + `marketing-header`/`marketing-footer` + page) so the Phase 4 privacy/terms pages inherit the same public chrome. The demo (`TabletDemo`, client component) is a self-driving ~21 s looping journey on the tablet-depiction idiom: route line composed via `@shared/announcements`, "Next stop" hero advancing through five stops (one deliberately long so the marquee shows every cycle), the stop rail progressing, and the terminating announcement firing as the 500 ms flash inversion then the text overlay (device's 8 s hold compressed to 4 s). It self-measures overflow and marquees via the same WAAPI keyframe shape as the simulator's `TickerLine` (no physical-mm claims), pauses off-screen and in background tabs (IntersectionObserver + visibilitychange), and renders a static mid-journey frame under `prefers-reduced-motion`. Page sections: hero → problem (PSVAR obligation vs thousands-per-vehicle bespoke AV) → BYO-tablets + subscription proposal → four steps on the product's stop-rail idiom (dashboard tokens, not `--tablet-*`) → plain-English compliance → fleet feature grid → pricing placeholder (`£— / vehicle / month`, structure only) → native-`details` FAQ → final CTA, with a minimal once-only `Reveal` scroll wrapper (SSR-visible, reduced-motion-safe). Routing landed atomically: the old `/` redirect stub deleted, `'/'` removed from `DASHBOARD_PATHS` (comment block rewritten — its rationale cited the deleted stub), `isDashboardPath` simplified, and the `(auth)` layout's logged-in redirect retargeted to `/routes`. Two new theme-invariant depiction tokens (`--tablet-flash-ground` `#f0f0f0`, `--tablet-flash-ink` `#161616`) extend the `--tablet-*` block. SEO scaffolding: absolute page title + OpenGraph, `metadataBase` via `siteUrl()`, `robots.ts` (dashboard/auth paths disallowed), `sitemap.ts`.
